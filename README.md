# 🛡️ WebGuard Island（資安靈動島）

一款輕量級的 Chrome / Edge（Manifest V3）瀏覽器資安外掛。在網頁右上角提供「靈動島」藥丸型即時風險儀表板，支援**五色風險燈號、載完 3 秒自動縮小成小圓球、免點假 X 的 `KO 廣告` 工具、三大黑名單手動更新與直接封鎖、大陸 IP 本地記憶，以及一鍵複製給 AI（Gemini）分析**。

> 📺 **操作教學影片（約 75 秒）**：[點此觀看 YouTube 教學](https://youtu.be/jYwyegz5YuQ)

## ✨ 靈動島五色狀態說明（優先級由高到低）

| 燈號顏色 | 狀態名稱 | 觸發條件 | 行為 |
| :--- | :--- | :--- | :--- |
| 🔴 **紅框** | 偵測側錄 | 第三方腳本監聽密碼欄（`password`）／信用卡欄，或未知匿名腳本監聽全域按鍵 | 脈衝警示並記錄來源腳本 |
| 🟡 **黑金** | 黑金封鎖 | 命中「防詐騙網域／威脅 IP／廣告追蹤」三大外部黑名單 | **底層 `declarativeNetRequest` 直接封鎖** |
| ⚫ **黑框** | 含大陸 IP | 頁面連線包含中國大陸（`CN`）IP 節點 | 本地永久記憶該 CN IP，下次免查 |
| 🟠 **橘框** | 廣告 / 跳板 | 偵測到一般廣告追蹤、跨站轉址跳板或可疑執行檔下載 | 標示來源網域與跳轉路徑 |
| 🟢 **綠框** | 安全網站 | 未偵測到上述風險 | 正常瀏覽 |

## 🚀 核心功能

1. **自動縮放小圓球（不擋畫面）**：網頁載入完成 3 秒後自動縮小為右上角 `30×30px` 狀態圓球；滑鼠移過去立刻展開，支援自由拖曳位置。
2. **🥊 KO 廣告（免點假 X）**：直接點藥丸上的 `KO 廣告`，滑鼠點選蓋版廣告即可從 DOM 直接移除並恢復頁面滾動，**完全不觸發網頁原本的點擊或跳轉事件**（按 `ESC` 退出）。
3. **黑金清單手動更新與直接封鎖**：
   * 整合 **Phishing Army**、**OpenPhish**（防詐騙網域）、**abuse.ch Feodo Tracker**、**Blocklist.de**（威脅 IP）、**Peter Lowe's List**（廣告追蹤）。
   * 透過專屬管理頁手動一鍵更新，更新後立即生效（已開啟的網頁按 F5 重新整理即可套用）。
4. **大陸 IP 查詢與本地記憶**：首次遇到新 IP 會呼叫外部 GeoIP 查詢，判定為大陸 IP 後永久快取於本地 `chrome.storage.local`，下次不再對外查詢。
5. **🤖 一鍵複製 AI 指令**：展開面板或進入管理頁，可將單筆可疑連線或整份手動封鎖列表一鍵複製成 AI 分析提示詞，直接貼給 Gemini / ChatGPT 分析用途與是否誤封。

## 📥 安裝步驟（Chrome / Edge）

1. 下載 `WebGuard-Island-v1.0.zip` 並解壓縮至任意資料夾（請勿刪除該資料夾）。
2. 在瀏覽器網址列輸入 `chrome://extensions`（Edge 為 `edge://extensions`）。
3. 開啟右上角的 **「開發人員模式」**。
4. 點擊左上角 **「載入未封裝項目」**，選擇解壓縮後的資料夾即完成安裝。

## 📁 檔案結構

* `manifest.json` — Manifest V3 擴充功能設定檔
* `background.js` — 背景服務：網路監控、GeoIP 快取、黑名單解析與 `declarativeNetRequest` 封鎖
* `page_hook.js` — 主執行環境掛鉤：精準偵測密碼／卡號與不明腳本側錄行為
* `content.js` — Shadow DOM 靈動島 UI、`KO 廣告` DOM 移除工具與複製報告
* `popup.html` / `popup.js` — 工具列快速檢視與快取管理彈窗
* `lists.html` / `lists.js` — 黑金清單手動更新中心、手動封鎖管理與 AI 指令複製

## ⚠️ 聲明與提醒

* 本外掛專注於**瀏覽器與網頁層級**的連線透視、廣告消除與黑名單阻斷；作業系統層級的防毒（如 `.exe` 木馬掃描）仍需搭配 Windows Defender 或系統防毒軟體。
* 專案原始碼完全公開透明，所有清單與設定皆儲存於本機 `chrome.storage.local`。
